# МАФ-конструктор (демо)

Мини-приложение Telegram / сайт: параметрические изделия завода «Армаф» — перголы, ротонды, скамьи, навесы,
контейнерные площадки, урны. 3D, чертёж, спецификация, раскрой, смета. Работает в браузере, без сервера и ИИ.

Демо-версия: полный комплект КД для КОМПАС выпускает серверный бот.
